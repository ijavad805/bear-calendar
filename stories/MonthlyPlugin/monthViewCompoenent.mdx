    ## How to Use
    First, install it with `npm install @bear-calendar/monthly`. Then, plug it into Bear Calendar with this way:

    ```typescript
    <BearCalendar plugins={[new MonthlyPlugin()]} view={"Monthly"} />
    ```

    You can add an event using this method:

    ```typescript
    <BearCalendar
      plugins={[new MonthlyPlugin()]}
      view={"Monthly"}
      config={{ locale: "en" }}
      events={[
        id: 1,
        title: "event"
        date: {
          start: "2024-10-05",
          end: "2024-10-10",
        }
      ]}
      {...props}
    />
    ```

    ## On drag and drop events
    for make the drag and rop enable you have to pass the `onDropEvent` prop, with this props it make the events draggable
    if you wanna cancel the event you have to return `false`, but if droping event is okay return `true` however you can not make it async

```typescript
  <BearCalendar
      {...props}
      onDropEvent: (event, newDate) => {
          console.log("event drop", event, newDate);
      },
  />
```

## Disable days

The `disabledDate` is call for each cell and ask you about disabling if you return true the day should be disabled
but if you return false it should not be disabled! For example on below example its make all saterday disable

```typescript
  <BearCalendar
      {...props}
      disabledDate: (event, newDate) => {
          return date.weekday() === 1;
      },
  />
```

You might be add your custom class for disable days it also accessable

```typescript
    <BearCalendar
      plugins={[new MonthlyPlugin({
        disableDayClass: "disable-day"
      })]}
      view={"Monthly"}
      {...props}
    />
```
